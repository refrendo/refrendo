# @refrendo/core

Motor del agente de trabajo verificado: bucle agéntico, puertas de calidad, diario transaccional con reversión, política de permisos y contabilidad de coste.

Este paquete es una pieza interna de [`refrendo`](https://www.npmjs.com/package/refrendo). Si buscas la herramienta, instala esa:

```bash
npm install -g refrendo
```

Documentación completa: https://github.com/TU-ORG/refrendo
