Cómo funciona

Tres fases. La tercera es la que nadie más hace.

No hay que cambiar de editor, ni de flujo, ni de proveedor. Refrendo se ejecuta donde ya tienes el código y usa las comprobaciones que ya tienes escritas.

01 · Contrato

Un objetivo, no una conversación

Le das qué quieres conseguir y los criterios que debe cumplir. El agente inspecciona el repositorio real y devuelve un plan con ficheros que ha visto, no con rutas inventadas.

02 · Ejecución gobernada

Con las manos atadas a propósito

Escribe, ejecuta tus tests y se corrige sobre la marcha. No puede salir del repositorio, no puede publicar nada fuera, y cada fichero que toca queda registrado para poder deshacerlo entero.

03 · Veredicto

Lo demuestra o lo deshace

Se ejecutan las puertas de tu proyecto. Si fallan, el agente recibe el error literal y lo arregla. Si tras varios intentos no llega a verde, revierte todo y te dice por qué. Nunca queda deuda que limpiar.

Por qué es distinto

Una opinión no es una prueba

El mercado se divide en herramientas que escriben más código y herramientas que opinan sobre él. Las dos aumentan la pila de cosas por revisar.

Asistentes de código

Producen más para revisar

Escriben rápido y bien. Pero cada línea que generan entra en la cola de revisión de alguien, y nada garantiza que funcione.

Revisores con IA

Añaden comentarios a la cola

Señalan problemas posibles sobre un cambio ya escrito. No ejecutan nada, así que no pueden afirmar que algo funcione — solo sugerirlo.

Refrendo

Quita trabajo de la cola

Lo que llega a revisión ya compila y pasa los tests. El revisor deja de preguntarse «¿esto funciona?» y se ocupa de lo que sí requiere criterio humano: si era la solución correcta.

Pagas por los cambios que pasan tus propios tests. Si el agente no lo consigue, revierte solo y no te cobramos.

El criterio de éxito no lo pone Refrendo: lo pone tu suite de tests, la misma que ya usas en tu CI. Por eso podemos cobrar por resultado sin pedirte que te fíes de nuestra definición de resultado. Es la única garantía de esta categoría que el cliente puede auditar por su cuenta.

Gobernanza

Para cuando alguien tenga que responder por ese cambio

Si trabajas en un sector regulado, la pregunta llega tarde o temprano: qué agente cambió esto, con qué autorización, y qué demostró que era seguro. Refrendo la contesta con un enlace.

Traza completa y reproducible

Cada run guarda plan, herramientas ejecutadas, aprobaciones, salida real de cada puerta, coste y veredicto. Compartible con un enlace firmado que caduca y abre solo ese run.

Rutas que no puede tocar

protectedPaths bloquea la escritura en tu pipeline de CI, tu infraestructura o lo que decidas. Pedírselo en un prompt es una petición; esto es un cerrojo.

Puertas obligatorias

requiredGates impide que un run se dé por verificado si falta una comprobación. Si desaparece tu suite de tests, eso es un fallo — no un silencio.

Presupuesto por run

Tope de gasto comprobado antes de cada petición al modelo. El coste real se contabiliza por run, por repositorio y por persona.

Nada sale sin que se vea

El agente no puede publicar: git push, npm publish y los comandos destructivos están bloqueados sin excepción. La publicación es un paso explícito de tu pipeline.

Autoría honesta

El commit va a nombre de quien lo pidió, con la procedencia en el pie del mensaje. El responsable de un cambio es una persona, aunque lo haya tecleado un agente.

Empezar

Tres comandos y lo tienes funcionando

Codigo abierto bajo Apache-2.0. No hay que registrarse para usarlo: se instala, se apunta a un repositorio con tests y ya.

1. Instalar

$ npm install -g refrendo

2. Ver que hace, sin clave de API ni conectar nada

$ refrendo serve --demo

3. Lanzarlo sobre un repositorio tuyo con tests

$ refrendo run "anade paginacion al endpoint de usuarios"     --accept "el endpoint acepta ?page y ?limit"     --max-cost 0.50

En integracion continua — abre el pull request solo si las puertas pasan

- uses: refrendo/refrendo@v0.0.1
  with:
    goal: ${{ github.event.issue.title }}
    anthropic-api-key: ${{ secrets.ANTHROPIC_API_KEY }}

Necesitas una clave de la API de Anthropic, que se factura aparte. Un cambio pequeno verificado cuesta unos 0,25 $ en tokens.
